Student Monitor

Landslide detection and slope monitoring. A low-cost early-warning aid. An ESP32 motion sensor on the slope sends live readings over Bluetooth to this page, which shows the risk level in real time.

How it works

1. Install the sensorFix an ESP32 with an MPU6050 motion sensor on the slope or retaining wall.
2. ConnectOpen this page in Chrome or Edge, press Connect ESP32 (Bluetooth) and pick LandslideNode.
3. MonitorTilt, vibration and motion events are scored as Low, Watch, Warning or Critical.

Build the sensor node

Parts: ESP32 board and MPU6050 sensor.
Wiring: VCC to 3.3V, GND to GND, SDA to pin 21, SCL to pin 22.
ESP32 Arduino sketch (copy into Arduino IDE)
// ESP32 + MPU6050 (I2C: SDA=21, SCL=22) -> Bluetooth LE -> Landslide app
#include <BLEDevice.h>
#include <BLEServer.h>
#include <BLEUtils.h>
#include <BLE2902.h>
#include <Wire.h>

#define SVC "6e400001-b5a3-f393-e0a9-e50e24dcca9e"
#define TX  "6e400003-b5a3-f393-e0a9-e50e24dcca9e"

BLECharacteristic *tx;
bool connected = false;

class CB : public BLEServerCallbacks {
  void onConnect(BLEServer *s) { connected = true; }
  void onDisconnect(BLEServer *s) { connected = false; BLEDevice::startAdvertising(); }
};

int16_t read16() {
  int16_t hi = Wire.read();
  int16_t lo = Wire.read();
  return (hi << 8) | lo;
}

void setup() {
  Wire.begin();
  Wire.beginTransmission(0x68); Wire.write(0x6B); Wire.write(0); Wire.endTransmission(true); // wake MPU6050

  BLEDevice::init("LandslideNode");
  BLEServer *s = BLEDevice::createServer();
  s->setCallbacks(new CB());
  BLEService *v = s->createService(SVC);
  tx = v->createCharacteristic(TX, BLECharacteristic::PROPERTY_NOTIFY);
  tx->addDescriptor(new BLE2902());
  v->start();
  BLEDevice::getAdvertising()->addServiceUUID(SVC);
  BLEDevice::startAdvertising();
}

void loop() {
  Wire.beginTransmission(0x68); Wire.write(0x3B); Wire.endTransmission(false);
  Wire.requestFrom(0x68, 6, true);
  float ax = read16() / 16384.0;
  float ay = read16() / 16384.0;
  float az = read16() / 16384.0;
  if (connected) {
    String m = String(ax, 2) + "," + String(ay, 2) + "," + String(az, 2) + "\n"; // e.g. 0.01,-0.02,0.99
    tx->setValue(m.c_str());
    tx->notify();
  }
  delay(200);
}
Important safety notice
This is a monitoring aid and is not an official landslide warning system. Thresholds are illustrative and must be calibrated for each site by a qualified geotechnical engineer. Never rely on it alone for life-safety decisions; follow guidance from local authorities.

Compatibility

Bluetooth works in Chrome or Edge on Android and desktop. iPhone browsers do not support Web Bluetooth. Use Run demo to try the monitor without hardware.
